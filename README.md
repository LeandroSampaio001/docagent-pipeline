# DocAgent Pipeline

API REST desenvolvida em Python com **FastAPI** para gerenciar a ingestão, o processamento e a análise inteligente de documentos.

## 🚀 Sobre o Projeto
Este projeto tem como objetivo construir um pipeline automatizado de backend para tratamento e extração de dados de documentos, garantindo alta performance, documentação interativa e arquitetura escalável.

## 🛠️ Tecnologias Utilizadas
* **Python**
* **FastAPI**
* **Uvicorn**
* **Pydantic**
* **Python-Multipart**
